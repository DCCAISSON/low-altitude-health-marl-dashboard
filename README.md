# 低空健康服务 MARL 决策看板

本目录是 GitHub Pages 公开展示版，仅包含脱敏后的仿真结果和静态看板，不包含医院原始数据、项目申报材料、训练检查点或本机路径。

公开版支持查看：

- 研究结论摘要
- 训练曲线和主体策略曲线
- 最新回放与最佳回放
- 空间网络与公平约束
- 不同情景的结果对照

参数编辑、模型训练和报告导出需要在完整项目的本地平台中运行。

页面结果用于研究演示，不作为医疗诊断或正式政策结论。

本地预览：

```powershell
python -m http.server 8000
```

浏览器访问 `http://127.0.0.1:8000/`。
