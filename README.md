# 低空健康服务 MARL 决策看板

本仓库发布完整交互式看板，不包含医院原始数据、项目申报材料、训练检查点或本机路径。

页面支持：

- 研究结论摘要
- 训练曲线和主体策略曲线
- 最新回放与最佳回放
- 空间网络与公平约束
- 不同情景的结果对照
- 参数编辑与情景预览
- 模型训练与报告导出

模型训练通过 Web Worker 中的 Python 运行时在浏览器设备上执行，不依赖远程训练服务。首次打开时需要加载运行环境，训练耗时取决于设备性能和训练轮数。

本地预览：

```powershell
python -m http.server 8000
```

浏览器访问 `http://127.0.0.1:8000/`。
